# @rpgjs/battle-kit

The foundation shared by the RPGJS battle systems (`@rpgjs/turn-battle`, `@rpgjs/tactical-rpg`, and your own): battle sessions, participants, hooks of the game modules, reading and writing a player (`@rpgjs/battle-kit/server`); screen, controls, sound cues, client hooks, effect presets and screen impacts (`@rpgjs/battle-kit`); presentation clock and Visual Effect playback (`@rpgjs/battle-kit/pure`).

See [the guide](../../docs/guide/battle-kit.md).
