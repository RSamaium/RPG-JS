# Celestial sample artwork

Created with the built-in OpenAI `image_gen` tool on 2026-09-14, for the existing
Crystal Chronicles title, inventory, dialogue and character-selection stories.
No suitable artwork existed in `packages/ui-css` before generation. The WebP
files preserve the generated compositions and transparency; only encoding changed.
These are sample images, not engine-provided characters or items. They are excluded
from the npm package. All labels, menus and borders are live HTML/CSS, not image text.

## celestial-sanctuary.webp

Source: `exec-7771aaee-21ec-404d-8fdf-7013e09b4007.png`.
Final generation prompt:

> Use case: stylized-concept. Create an original premium hand-painted 2D fantasy RPG title-screen background, landscape 16:9. A forgotten celestial crystal sanctuary at blue twilight: on the RIGHT HALF, a monumental weathered ivory stone arch with astrolabe engravings encircling a floating luminous turquoise crystal, on an island of mossy marble terraces above a vast mist-filled mountain valley. Slender cypress silhouettes, trailing foliage, small warm lanterns, distant aqueduct and delicate waterfall. Art direction: sophisticated painterly game key art, visible fine brush textures, atmospheric perspective, beautiful soft edges, restrained warm antique gold and deep peacock blue, sublime mysterious quiet adventure. Composition specifically for a real interactive title menu: LEFT 45 PERCENT is calm dark blue mist and shadowed foliage with very low detail and low contrast, so cream typography and menu can be placed there in HTML. Right crystal and arch form the strong focal point, not centered. No text, no lettering, no logo, no buttons, no UI frames, no watermark, no characters, no photorealism. This is the actual background asset, not a mockup sheet.

## Typography

Cinzel is an unmodified Google Fonts distribution from
https://github.com/google/fonts/tree/main/ofl/cinzel, fetched 2026-09-14.
The binary and its SIL OFL license are bundled in `theme-default/fonts/`.
The astrolabe SVG is a code-authored decorative mask in `theme-default/`.
