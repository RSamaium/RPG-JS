Add a persistent server-authoritative skill and item hotbar with keyboard and radial gamepad controls, direct 1–0 Zelda-style menu assignment, CanvasEngine-compatible numeric bindings, focus-safe slot navigation, adaptive occupied slots, Action Battle targeting, cooldown and projectile integration, and Studio skill workflows executed through the native `onUse` hook. Also add translated Studio presentation fields, visual area targeting, phase-specific CanvasEngine cast/trail/impact presets, a default projectile renderer compatible with Studio skill records, and robust object-signal hydration for class and hotbar sync payloads.
