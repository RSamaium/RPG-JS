The `@rpgjs/common`, `@rpgjs/server`, `@rpgjs/client` and `@rpgjs/render-map2d` peer dependencies accept any compatible version (`^5.x`) instead of the exact version released with the package, like the other RPGJS packages. A minor release of those packages no longer forces a new major version of `@rpgjs/map-builder`.
