# Pixel Chat

This playground demonstrates the official `@rpgjs/chat` module with the
renderer-neutral `@rpgjs/ui-css/theme-pixel.css` theme.

- Enter a message and press Send.
- The server validates and broadcasts it to the current map.
- A server-side Pixel Guide answers through the chat moderation hook.
- The same chat behavior can use another CanvasEngine or Vue component.
