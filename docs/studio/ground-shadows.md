# Studio ground shadows

An element image generated by GPT Image can include both the object and a soft ground shadow in one transparent PNG or WebP. Enable **Keep embedded ground shadow below characters** in the tileset element configuration to separate the shadow at runtime.

Studio keeps the normal element in its usual Y-sorted layer and renders the extracted shadow in a ground layer below heroes, NPCs and events. The original media file is not duplicated: derived textures are cached from the element rectangle while the map is rendered.

The extraction is intentionally opt-in and conservative. It only moves dark, semi-transparent pixels from the lower area of the element. Use images with an isolated object, transparent background, and one soft floor shadow. Disable the option for smoke, glass, reflections, or other translucent artwork that should remain part of the object.

This is a client-only visual behavior and works in standalone games as well as streamed MMORPG Studio maps.
