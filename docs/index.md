# RPGJS v5

Create your RPG or MMORPG in JavaScript.

RPGJS v5 is a revolutionary framework for building 2D RPG games. It features the **Are Logic Engine**, moving beyond traditional scripted gameplay into a world of heuristic-driven evolution, procedural infinity, and autonomous civilizations.

## 🌟 Emergent Systems

Unlike traditional engines, RPGJS v5 is built on five core axioms:
- **Relational Integrity (A1):** The world is a dynamic graph.
- **Historical Persistence (A2):** The world remembers.
- **Emergent Interaction (A3):** Systems react non-linearly.
- **Watchdog Enforcement (A4):** The world stays stable.
- **Continuous Integration (A5):** Actions drive evolution.

## Explore the docs

The documentation is organized into three tabs:

- **Guide** for setup, gameplay systems, and the **Emergent Engine**.
- **API** for hooks and extension points.

## Quick start

```bash
npx degit rpgjs/starter#v5 my-rpg-game
cd my-rpg-game
npm install
# npm run dev
```

Open `http://localhost:5173`.

## Highlights

- **Heuristic Wave Engine:** 13-dimensional world state.
- **Infinite Procedural World:** Chunk-based generation.
- **Autonomous Civilizations:** AI factions that evolve.
- **Emergent Narratives:** History-driven quests and lore.
